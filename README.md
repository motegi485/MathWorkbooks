# 情報系のための数学 問題集シリーズ

情報系の大学生・大学院進学をめざす人のための、独学用の数学問題集です。
機械学習・信号処理・アルゴリズムなどを学ぶ土台となる数学を、手を動かして身につけることを目的としています。

各分野は『問題集』と『解答解説集』の2冊組で、問題番号が完全に対応しています（問 3.4 の解説は 解 3.4）。
問題には難易度（★／★★／★★★）が付いており、基礎の確認から大学院入試レベルまで段階的に進められます。

### 線形代数
ベクトルと行列から出発し、連立一次方程式・行列式・基底と次元・固有値と対角化・内積と直交性を経て、
特異値分解(SVD)と数値線形代数まで。機械学習・画像処理・CG の共通言語をつくります。

### 微分積分・最適化
1変数の微積分（極限・テイラー展開・広義積分）から多変数（偏微分と勾配・ヘッセ行列・重積分）へ進み、
凸解析、勾配降下法、ニュートン法、KKT条件、双対性まで。学習アルゴリズムが「なぜ動くのか」に届きます。

### 確率・統計
確率の基礎と条件付き確率・ベイズの定理から、確率変数と分布、大数の法則と中心極限定理、
推定・検定・回帰、ベイズ統計、確率過程（マルコフ連鎖・カルマンフィルタ）、情報理論、
そして測度論的確率論の入口まで。

### フーリエ解析
複素数とオイラーの公式、関数の内積と直交性から出発し、フーリエ級数・フーリエ変換・畳み込みとLTIシステム・
デルタ関数・時間周波数解析を経て、標本化定理・DTFT・DFT・FFT へ。最後に2次元変換と画像、変調と通信、
不規則信号のスペクトルを扱い、連続の理論と計算機の中の離散的な変換をつなぎます。

## 構成

```
index.html                        トップページ（4分野へのリンク）
linear-algebra/
  workbook.html                   問題集
  solutions.html                  解答解説集
calculus-optimization/            微分積分・最適化（同じ2ファイル構成）
probability-statistics/           確率・統計（同じ2ファイル構成）
fourier-analysis/                 フーリエ解析（同じ2ファイル構成）
```

各 HTML は完全に自己完結しています（数式表示に MathJax の CDN を使う以外、外部依存はありません）。
`index.html` をブラウザで開けばそのまま読めます。ビルド作業はありません。
